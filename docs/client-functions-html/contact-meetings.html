Карточка контакта и управление встречами

Детальная работа с конкретным клиентом: данные профиля, встречи, платежи, заметки, Telegram и календарные ссылки.

Описание ниже написано простым языком. В каждой карточке есть короткий пример из обычной работы.

1. Карточка контакта (`/contact/[id]`) — общая структура

Карточка контакта разделена на вкладки: Обзор, Расписание, Платежи, Заметки.

Обзор контакта

Простыми словами: Показывает профиль клиента, основные поля, статистику по встречам/платежам/заметкам.

Зачем это нужно: Менеджер видит полную картину клиента в одном месте.

Пример из жизни: Например, клиент сам выбрал слот на пятницу 15:00, а менеджеру не пришлось согласовывать время вручную в переписке.

Редактирование полей профиля

Простыми словами: Базовые поля контакта (включая заметки в карточке профиля) можно редактировать.

Зачем это нужно: Помогает поддерживать CRM в актуальном состоянии.

Пример из жизни: Например, менеджер открывает карточку клиента и сразу видит: встречи, оплаты, заметки и важные теги.

Вкладки карточки

Простыми словами: Переключение между обзором, расписанием, платежами и заметками с сохранением вкладки в URL.

Зачем это нужно: Удобная навигация внутри карточки клиента.

Пример из жизни: Например, клиент сам выбрал слот на пятницу 15:00, а менеджеру не пришлось согласовывать время вручную в переписке.

Статистика по клиенту

Простыми словами: Показываются агрегаты: число встреч, план/факт по оплатам, количество заметок.

Зачем это нужно: Полезно для быстрых созвонов и ревью клиента.

Пример из жизни: Например, клиенту отправили ссылку на оплату в Telegram, он оплатил, а вы сразу видите статус в системе.

На обзоре можно видеть назначенные теги клиента и добавлять описания/комментарии к ним.

Просмотр назначенных тегов

Простыми словами: Показываются теги клиента с типом (цель/боль/опыт).

Зачем это нужно: Даёт быстрый контекст о клиенте.

Пример из жизни: Например, менеджер открывает карточку клиента и сразу видит: встречи, оплаты, заметки и важные теги.

Комментарий к тегу

Простыми словами: К каждому тегу можно сохранить пояснение/контекст.

Зачем это нужно: Полезно для персонализации коммуникации и передач дел между менеджерами.

Пример из жизни: Например, менеджер открывает карточку клиента и сразу видит: встречи, оплаты, заметки и важные теги.

Пример из жизни: Например, клиенту отправили ссылку на оплату в Telegram, он оплатил, а вы сразу видите статус в системе.

Зачем это нужно: Менеджер видит, привязан ли контакт к Telegram.
