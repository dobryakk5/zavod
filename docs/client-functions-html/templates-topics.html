1. Шаблоны контента (`/templates`)

Шаблоны задают параметры генерации постов и промпты для AI.

Список шаблонов

Простыми словами: Таблица шаблонов показывает тип, тон, длину, язык и сокращённые промпты.

Зачем это нужно: Удобно держать библиотеку шаблонов для разных задач.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

Создание шаблона

Простыми словами: Страница `/templates/new` открывает форму создания нового шаблона.

Зачем это нужно: Команда может быстро запускать новые форматы контента.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Редактирование шаблона

Простыми словами: Страница `/templates/[id]` помогает изменять параметры шаблона и промпты.

Зачем это нужно: Шаблон можно дорабатывать по результатам публикаций.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Удаление шаблона

Простыми словами: Шаблон удаляется с подтверждением.

Зачем это нужно: Поддерживает порядок в библиотеке шаблонов.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

2. Поля и логика формы шаблона

Форма шаблона включает параметры контента и промпты для разных сценариев генерации.

Название шаблона

Простыми словами: Человекочитаемое название для поиска и выбора в планировании постов.

Зачем это нужно: Упрощает работу контент-менеджера.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Тип контента

Простыми словами: Выбор типа (продающий, экспертный и др.) с возможностью добавить свой тип.

Зачем это нужно: Помогает стандартизировать форматы под бизнес-задачи.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Тон

Простыми словами: Выбор тона (профессиональный, дружелюбный и др.) с возможностью добавить свой.

Зачем это нужно: Помогает держать единый стиль бренда.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

Длина текста

Простыми словами: Задаётся желаемый объём текста в символах.

Зачем это нужно: Управляет плотностью и форматом поста.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Язык

Простыми словами: Язык шаблона задаётся при создании; при редактировании показывается как фиксированный.

Зачем это нужно: Помогает вести шаблоны для разных языков.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

SEO-подсказка (SEO prompt)

Простыми словами: Промпт для генерации по SEO-ключам с поддержкой переменных.

Зачем это нужно: Нужно для при генерации SEO-ориентированного контента.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Trend-подсказка (Trend prompt)

Простыми словами: Промпт для генерации по трендам/темам.

Зачем это нужно: Ускоряет выпуск реактивного контента на тренды.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Дополнительные инструкции

Простыми словами: Поле для уточнения правил и ограничений генерации.

Зачем это нужно: Повышает повторяемость качества контента.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

3. Темы (`/topics`)

Темы используются для сбора трендов и подготовки контентных направлений.

Список тем

Простыми словами: Таблица тем показывает название, описание, ключевые слова и выбранные источники данных.

Зачем это нужно: Даёт обзор тематического портфеля проекта.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

Создание темы

Простыми словами: Можно создать новую тему для последующего поиска трендов и контента.

Зачем это нужно: Добавляет новое направление в систему мониторинга.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Переход в карточку темы

Простыми словами: Клик по теме открывает детальную страницу `/topics/[id]`.

Зачем это нужно: Помогает работать с трендами и действиями по теме.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

Действия по теме

Простыми словами: Через `TopicActions` доступны действия для запуска поиска/обновления данных по теме.

Зачем это нужно: Ускоряет работу с трендовыми материалами.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

Удаление темы

Простыми словами: Тема удаляется из списка с подтверждением.

Зачем это нужно: Помогает убирать неактуальные направления.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

4. Карточка темы и тренды

На странице темы показывается контекст темы и найденные тренды.

Просмотр ключевых слов темы

Простыми словами: Ключевые слова показываются в виде бейджей.

Зачем это нужно: Пользователь быстро видит семантическое ядро темы.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Источники темы

Простыми словами: Отмечаются подключённые источники: Google Trends, News API, YouTube.

Зачем это нужно: Понятно, откуда приходят трендовые материалы.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.

Список трендов по теме

Простыми словами: Отдельный блок показывает найденные тренды (карточки).

Зачем это нужно: Материал можно использовать для идей постов/статей.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Обновление трендов через действия

Простыми словами: После запуска поиска через `TopicActions` список трендов пополняется/обновляется.

Зачем это нужно: Сервис становится источником актуальных инфоповодов.

Пример из жизни: Например, вы сделали отдельный шаблон для продающих постов и потом запускаете генерацию по нему каждую неделю.
