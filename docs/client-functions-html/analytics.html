Аналитика: каналы, сайт, подборки и TGStat

Раздел для анализа каналов, проекта, конкурентов и сайта с сохранением истории и отчётов.

Где находится

  • Главный раздел аналитики: `/analytics`
  • TGStat-подбор каналов: `/analytics/tgstat`
  • Детальный отчёт канала: `/analytics/[analysisId]`
  • Отчёт подборки за неделю: `/analytics/rep/[id]`
  • Список страниц скана сайта: `/analytics/website/[scanId]/list`

1. Вкладка «Один канал»

Используется для анализа отдельных каналов (в том числе конкурентов).

Выбор типа канала

Простыми словами: Пользователь выбирает платформу анализа: Telegram, Instagram или YouTube.

Зачем это нужно: Сервис подстраивает формат ссылки и подсказки ввода.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Проверка формата ссылки/username

Простыми словами: Для выбранной платформы отображаются примеры допустимых ссылок и идентификаторов.

Зачем это нужно: Снижает ошибки запуска анализа.

Пример из жизни: Например, перед запуском рекламы вы быстро проверяете конкурентов и смотрите, какие темы у них реально работают.

Запуск анализа канала

Простыми словами: По введённой ссылке запускается AI-анализ канала.

Зачем это нужно: Пользователь получает отчёт по метрикам, темам и аудитории.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

История аналитики

Простыми словами: Список предыдущих запусков с датой, статусом и переходом в детальный отчёт.

Зачем это нужно: Можно возвращаться к прошлым результатам и сравнивать выводы.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Детальный отчёт канала

Простыми словами: Страница `/analytics/[analysisId]` показывает метрики, темы, формат публикаций, профиль аудитории и др.

Зачем это нужно: Клиент получает структурированный разбор канала.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Публичная ссылка на отчёт

Простыми словами: Из детального отчёта можно сгенерировать share-ссылку для просмотра без основного входа.

Зачем это нужно: Удобно для отправки клиенту/команде.

Пример из жизни: Например, менеджер открывает карточку клиента и сразу видит: встречи, оплаты, заметки и важные теги.

Перенос профиля ЦА в настройки клиента

Простыми словами: Из отчёта можно обновить описание аудитории клиента (avatar/pains/desires/objections).

Зачем это нужно: Экономит время на перенос аналитики в рабочие настройки проекта.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

2. Вкладка «Мой проект»

Раздел для анализа собственных каналов проекта и динамики по ним.

Сохранение каналов проекта

Простыми словами: Пользователь задаёт каналы проекта (Telegram/Instagram/YouTube) в одном месте.

Зачем это нужно: Эти данные используются для регулярного анализа проекта.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Запуск анализа проекта

Простыми словами: После сохранения каналов можно запустить анализ проекта одной кнопкой.

Зачем это нужно: Получается сводный снимок по собственным каналам.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Снимок метрик и дельты

Простыми словами: Показываются текущие значения и изменения к прошлому запуску (подписчики, просмотры, реакции, комментарии).

Зачем это нужно: Помогает быстро оценить рост/просадку.

Пример из жизни: Например, перед запуском рекламы вы быстро проверяете конкурентов и смотрите, какие темы у них реально работают.

График временных рядов

Простыми словами: Можно выбрать каналы и метрики для отображения на одном графике.

Зачем это нужно: Удобно для динамического сравнения каналов и показателей.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Автообновление активного анализа

Простыми словами: Если анализ ещё выполняется, сервис периодически обновляет статус и прогресс.

Зачем это нужно: Пользователь видит реальное состояние процесса без ручного обновления.

Пример из жизни: Например, перед запуском рекламы вы быстро проверяете конкурентов и смотрите, какие темы у них реально работают.

3. Вкладка «Подборка за неделю»

Сбор контента из источников за неделю для анализа и идей публикаций.

Настройка источников контента

Простыми словами: Поддерживаются списки Telegram-каналов, RSS/Atom, YouTube-каналов, Instagram-аккаунтов и VK-сообществ.

Зачем это нужно: Можно собрать единый пул источников для мониторинга ниши.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Сохранение источников

Простыми словами: Списки источников сохраняются в настройках клиента/проекта.

Зачем это нужно: Не нужно заполнять заново перед каждым запуском.

Пример из жизни: Например, менеджер открывает карточку клиента и сразу видит: встречи, оплаты, заметки и важные теги.

Запуск недельной подборки

Простыми словами: Сервис запускает сбор и обработку публикаций по источникам за неделю.

Зачем это нужно: Получается пакет отчётов и идей по контенту.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Статусы пакетной обработки

Простыми словами: Показываются статусы пакета и отдельных источников: в очереди, в работе, готово, ошибка.

Зачем это нужно: Удобно контролировать процесс без технической панели.

Пример из жизни: Например, перед запуском рекламы вы быстро проверяете конкурентов и смотрите, какие темы у них реально работают.

Страница отчёта подборки

Простыми словами: `/analytics/rep/[id]` показывает собранные посты, идеи, длину текста, рекомендации к использованию.

Зачем это нужно: Клиент получает понятный материал для контент-планирования.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

4. Вкладка «Website» (анализ сайта)

Анализирует сайт и помогает связать страницы с семантикой/структурой.

Запуск скана сайта

Простыми словами: Пользователь вводит URL сайта и запускает сканирование.

Зачем это нужно: Сервис собирает страницы и базовые данные для анализа.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

История сканов

Простыми словами: Список запусков сканирования с датой, статусом и прогрессом.

Зачем это нужно: Можно отслеживать новые и прошлые сканы.

Пример из жизни: Например, перед запуском рекламы вы быстро проверяете конкурентов и смотрите, какие темы у них реально работают.

Список страниц сайта

Простыми словами: `/analytics/website/[scanId]/list` показывает таблицу страниц с URL, заголовком и top-словами/wordstat-данными.

Зачем это нужно: Удобно для аудита структуры сайта и контента.

Пример из жизни: Например, вы продаёте кухни и хотите понять, что люди ищут чаще: «кухня на заказ» или «кухня под ключ».

Связка с mind map сайта

Простыми словами: Если у скана есть карта, сервис использует данные узлов и слов для расширенного отображения.

Зачем это нужно: Помогает видеть структуру сайта и семантику в одной модели.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Переход к карте сайта

Простыми словами: Из аналитики можно открыть mind map (если построена).

Зачем это нужно: Ускоряет работу с архитектурой страниц.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

5. TGStat: подбор Telegram-каналов

Отдельная страница аналитики для поиска и отбора релевантных Telegram-каналов.

Категории и подкатегории TGStat

Простыми словами: Пользователь проходит путь Категория → Подкатегория → Каналы.

Зачем это нужно: Быстро находит релевантные ниши Telegram.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Просмотр каналов по категории/тегу

Простыми словами: Сервис показывает список каналов, их метрики и служебные данные из TGStat.

Зачем это нужно: Упрощает выбор каналов для анализа/мониторинга.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Избранные каналы

Простыми словами: Каналы можно добавить в избранное и поддерживать собственный список наблюдения.

Зачем это нужно: Формирует персональный пул конкурентов и ориентиров.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Удаление из избранного

Простыми словами: Ненужные каналы удаляются из списка избранных без удаления из TGStat.

Зачем это нужно: Список остаётся актуальным.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Рекомендации по нише и продукту

Простыми словами: Сервис может запросить рекомендации TGStat на основе настроек проекта (ниша/продукт).

Зачем это нужно: Помогает быстрее найти релевантные каналы без ручного перебора.

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

Запуск аналитики канала из избранного

Простыми словами: Из карточки избранного канала можно сразу запустить аналитический отчёт в основном модуле аналитики.

Зачем это нужно: Сокращает путь «нашёл канал → проанализировал».

Пример из жизни: Например, вы анализируете канал конкурента и получаете список тем, которые можно адаптировать под свой проект.

6. Дополнительные аналитические страницы

Это подстраницы, которые используются как продолжение сценариев из главной аналитики.

Деталь анализа канала (`/analytics/[analysisId]`)

Простыми словами: Полный отчёт по метрикам, темам, аудитории, влиянию автора, форматам и ритму публикаций.

Зачем это нужно: Основная страница для обсуждения результатов с клиентом.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Отчёт подборки (`/analytics/rep/[id]`)

Простыми словами: Просмотр недельной подборки по источникам с разбором ссылок и идей контента.

Зачем это нужно: Нужно для в контент-планировании.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Список страниц сайта (`/analytics/website/[scanId]/list`)

Простыми словами: Таблица страниц скана сайта с ключевыми словами и ссылками.

Зачем это нужно: Полезна для SEO-аудита и проектирования структуры.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.
