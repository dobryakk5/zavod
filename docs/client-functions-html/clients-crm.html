1. Раздел «Клиенты» (`/clients`) — общая структура

Главный CRM-раздел объединяет несколько вкладок и быстрый индикатор ближайшей встречи.

Индикатор ближайшей встречи

Простыми словами: Вверху страницы показывается ближайшая запланированная встреча с ссылкой на карточку контакта.

Зачем это нужно: Менеджер быстро видит следующий важный контакт.

Пример из жизни: Например, клиент сам выбрал слот на пятницу 15:00, а менеджеру не пришлось согласовывать время вручную в переписке.

Вкладки CRM

Простыми словами: Доступны вкладки: Клиенты, Расписание, Уровень сервиса, Теги, Платежи, ChatBot.

Зачем это нужно: Один раздел закрывает ключевые CRM-процессы.

Пример из жизни: Например, клиент сам выбрал слот на пятницу 15:00, а менеджеру не пришлось согласовывать время вручную в переписке.

Навигация вкладок через URL-параметры

Простыми словами: Активные вкладки сохраняются в query-параметрах (`tab`, `scheduleTab`).

Зачем это нужно: Можно отправлять коллегам точные ссылки на нужный экран.

Пример из жизни: Например, вы отправляете коллеге ссылку сразу на нужную вкладку, а не объясняете по шагам, куда нажимать.

7. Вкладка «ChatBot» и редактор цепочек

Список цепочек и визуальный редактор логики диалога для чат-бота.

Список чат-цепочек
