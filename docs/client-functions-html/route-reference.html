1. Как использовать карту

Эта страница нужна для проверки полноты и для быстрых ссылок на нужный раздел каталога.

Проверка покрытия

Простыми словами: Сверьте маршрут интерфейса со ссылкой на нужный раздел каталога.

Зачем это нужно: Помогает убедиться, что клиентская функция описана.

Пример из жизни: Например, вы отправляете коллеге ссылку сразу на нужную вкладку, а не объясняете по шагам, куда нажимать.

Поиск служебных маршрутов

Простыми словами: В таблице отмечаются редиректы и callback-страницы (например, `/pay`, `/auth/vk/callback`).

Зачем это нужно: Удобно объяснять клиенту переходы между страницами.

Пример из жизни: Например, вы отправляете коллеге ссылку сразу на нужную вкладку, а не объясняете по шагам, куда нажимать.

Работа с динамическими маршрутами

Простыми словами: Сегменты вида `[id]`, `[client_id]`, `[mapId]` и др. сохранены в том же виде, что и в проекте.

Зачем это нужно: Техническая и пользовательская документация остаются согласованными.

Пример из жизни: Например, вы отправляете коллеге ссылку сразу на нужную вкладку, а не объясняете по шагам, куда нажимать.
