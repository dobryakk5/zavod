1. Что закрывает этот блок

Блок собран для менеджеров и операторов, которые ведут клиента до и после оплаты.

CRM и входящие

Простыми словами: Единый инбокс, список клиентов, календарь, задачи и платежи в одном разделе CRM.

Зачем это нужно: Менеджер видит текущую работу по клиентам в одном месте.

Пример из жизни: Например, клиент сам выбрал слот на пятницу 15:00, а менеджеру не пришлось согласовывать время вручную в переписке.

Воронка продаж

Простыми словами: Сводный блок по этапам и конверсии показывает, где теряются лиды и где есть рост.

Зачем это нужно: Помогает управлять продажами по данным, а не по ощущениям.

Пример из жизни: Например, вы делаете это один раз в интерфейсе, и дальше команда тратит меньше времени на ручную работу.

Карточка контакта

Простыми словами: Детальная работа с конкретным клиентом: встречи, платежи, заметки, теги и пакеты услуг.

Зачем это нужно: Все важные действия по клиенту собраны в одном экране.

Пример из жизни: Например, клиент сам выбрал слот на пятницу 15:00, а менеджеру не пришлось согласовывать время вручную в переписке.

Публичная страница клиента

Простыми словами: Покупки, запись на слоты, цифровая выдача и реферальная программа.

Зачем это нужно: Клиент может сам выполнять часть действий без менеджера.

Пример из жизни: Например, клиент сам выбрал слот на пятницу 15:00, а менеджеру не пришлось согласовывать время вручную в переписке.

CRM-автоматизации по событиям

Простыми словами: Сервис может сама запускать сценарии после важных событий: оплата, перенос встречи, отмена встречи.

Зачем это нужно: Менеджеру не нужно вручную писать одинаковые сообщения после каждого события.

Как это сделать: В CRM откройте вкладку ChatBot, настройте цепочки «После оплаты», «После встречи» и «Перенос встречи», затем переведите их в статус active.

Пример из жизни: Например, клиент оплатил консультацию, и система сама отправила инструкцию: что подготовить и где будет ссылка на встречу.

2. Рекомендуемый порядок

Удобный путь для ежедневной операционной работы и продаж.

Шаг 1. CRM

Простыми словами: Начните со страницы CRM, чтобы увидеть воронку, входящие и общую нагрузку по клиентам.

Зачем это нужно: Даёт быстрый управленческий снимок дня.

Пример из жизни: Например, менеджер открывает карточку клиента и сразу видит: встречи, оплаты, заметки и важные теги.

Шаг 2. Карточка контакта

Простыми словами: Откройте карточку контакта для точечной работы: встречи, оплаты, заметки и сервисные детали.

Зачем это нужно: Помогает довести конкретный кейс до результата.

Пример из жизни: Например, клиенту отправили ссылку на оплату в Telegram, он оплатил, а вы сразу видите статус в системе.

Шаг 3. Публичная страница и оплаты

Простыми словами: Перейдите к публичной странице клиента и маршрутам оплаты, если нужно оформить покупку или выдать доступ.

Зачем это нужно: Закрывает путь клиента от интереса до оплаты и сопровождения.

Пример из жизни: Например, вы отправляете коллеге ссылку сразу на нужную вкладку, а не объясняете по шагам, куда нажимать.
