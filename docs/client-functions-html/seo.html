Просмотр смысловых групп

Простыми словами: Список групп по проекту с типом, статусом и базовой информацией.

Зачем это нужно: Помогает видеть общую карту смыслов проекта.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Простыми словами: Можно добавить новую группу с названием, описанием, scope, ожидаемым числом кластеров и статусом.
