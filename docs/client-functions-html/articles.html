Статьи: создание и SEO-оценка

Пошаговый конструктор SEO-статей и инструмент анализа/переписывания готовых текстов.

Где находится

  • Список и запуск статьи: `/articles`
  • Карточка статьи: `/articles/[id]`
  • Совместимый редирект: `/articles/new/[id]`
/articles /articles/[id] /articles/new/[id]
Быстрый переход по странице
1. Список статей и запуск создания 2. SEO-оценка готового текста/страницы 3. Детальная страница статьи (`/articles/[id]`) 4. Маршруты-обёртки и совместимость

1. Список статей и запуск создания

Главная страница `/articles` совмещает список статей и старт нового процесса генерации.

Список статей

Простыми словами: Таблица показывает Wordstat-фразу, дату и статус статьи.

Зачем это нужно: Помогает контролировать очередь статей и этапы готовности.

Пример из жизни: Например, вы продаёте кухни и хотите понять, что люди ищут чаще: «кухня на заказ» или «кухня под ключ».

Статусы этапов статьи

Простыми словами: Поддерживаются статусы: Wordstat, контекст предложен/выбран, скелет готов, статья составлена, правки внесены, ошибка.

Зачем это нужно: Команда видит текущее состояние каждой статьи.

Пример из жизни: Например, вы продаёте кухни и хотите понять, что люди ищут чаще: «кухня на заказ» или «кухня под ключ».

Запуск статьи по Wordstat-фразам

Простыми словами: Можно вставить одну или несколько фраз (по строкам) и запустить создание статьи.

Зачем это нужно: Сервис создаёт заготовку и открывает детальный экран статьи.

Пример из жизни: Например, вы продаёте кухни и хотите понять, что люди ищут чаще: «кухня на заказ» или «кухня под ключ».

Удаление статьи

Простыми словами: Статья удаляется из списка с подтверждением.

Зачем это нужно: Убирает неактуальные черновики.

Пример из жизни: Например, вы берёте фразу из Wordstat, сервис собирает структуру статьи, а редактор потом быстро вносит правки.

2. SEO-оценка готового текста/страницы

Вкладка «Оценить» помогает проверить существующую статью по URL или вставленному тексту.

Анализ по URL или тексту

Простыми словами: Пользователь вводит ссылку или текст статьи и, при желании, основную Wordstat-фразу.

Зачем это нужно: Можно проверять как свои, так и существующие материалы.

Пример из жизни: Например, вы продаёте кухни и хотите понять, что люди ищут чаще: «кухня на заказ» или «кухня под ключ».

Режим «Аналитика»

Простыми словами: Показывает базовый SEO-анализ по ключам и покрытию кластера.

Зачем это нужно: Помогает понять, что уже хорошо, а что нужно доработать.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Режим «Рекомендации»

Простыми словами: Генерирует рекомендации по улучшению материала.

Зачем это нужно: Даёт список действий для редактора/копирайтера.

Пример из жизни: Например, вы берёте фразу из Wordstat, сервис собирает структуру статьи, а редактор потом быстро вносит правки.

Режим «Rewrite / SEO plan»

Простыми словами: Формирует план переписывания/SEO-усиления статьи.

Зачем это нужно: Помогает быстро подготовить ТЗ на переработку текста.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Вывод найденных/пропущенных ключей

Простыми словами: Показываются найденные и недостающие ключевые фразы, покрытие кластеров и главный кластер.

Зачем это нужно: Даёт понятную картину SEO-плотности и полноты темы.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

3. Детальная страница статьи (`/articles/[id]`)

Основной рабочий экран генерации статьи с пошаговым процессом и редактированием.

Шаг 1: Wordstat

Простыми словами: Просмотр базовой фразы и исходных данных статьи.

Зачем это нужно: Стартовая точка процесса генерации.

Пример из жизни: Например, вы продаёте кухни и хотите понять, что люди ищут чаще: «кухня на заказ» или «кухня под ключ».

Шаг 2: Контекст

Простыми словами: Выбор/создание контекстных вариантов для будущей статьи.

Зачем это нужно: Помогает задать правильный угол подачи материала.

Пример из жизни: Например, вы берёте фразу из Wordstat, сервис собирает структуру статьи, а редактор потом быстро вносит правки.

Шаг 3: SEO блоки

Простыми словами: Генерация структуры статьи по блокам (H2, микро-интенты, ключевые фразы).

Зачем это нужно: Статья строится как контролируемая SEO-структура, а не одним куском текста.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Шаг 4: Результат

Простыми словами: Финальная сборка и просмотр результата статьи.

Зачем это нужно: Можно подготовить итоговый текст для публикации/редактора.

Пример из жизни: Например, вы заранее планируете посты на неделю и видите в календаре, что выйдет в Telegram и VK.

Ручное редактирование SEO-блоков

Простыми словами: Каждый блок можно корректировать вручную: подзаголовок, подзапрос, ключи, текст.

Зачем это нужно: Сохраняется контроль качества и экспертная правка.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

Генерация отдельных блоков

Простыми словами: Можно сгенерировать только выбранный блок.

Зачем это нужно: Экономит время при точечной доработке.

Пример из жизни: Например, вы берёте фразу из Wordstat, сервис собирает структуру статьи, а редактор потом быстро вносит правки.

Генерация всех блоков

Простыми словами: Одна кнопка запускает генерацию текста для всех блоков.

Зачем это нужно: Ускоряет подготовку полного черновика статьи.

Пример из жизни: Например, вы берёте фразу из Wordstat, сервис собирает структуру статьи, а редактор потом быстро вносит правки.

Перегенерация блока

Простыми словами: Для блока доступен повторный запуск с подтверждением.

Зачем это нужно: Помогает улучшить слабые фрагменты без пересборки всей статьи.

Пример из жизни: Например, вы берёте фразу из Wordstat, сервис собирает структуру статьи, а редактор потом быстро вносит правки.

SEO preview и статистика

Простыми словами: Внутри статьи есть просмотр SEO-представления и базовая SEO-статистика по результату.

Зачем это нужно: Удобно перед финальной редактурой и публикацией.

Пример из жизни: Например, перед запуском новой услуги вы собираете запросы и смотрите, какие сайты уже занимают выдачу.

4. Маршруты-обёртки и совместимость

Часть маршрутов поддерживает старые ссылки и редиректы на основной экран статьи.

Редирект `/articles/new/[id]` → `/articles/[id]`

Простыми словами: Сервис перенаправляет старый/промежуточный маршрут на актуальную карточку статьи.

Зачем это нужно: Старые ссылки продолжают работать.

Пример из жизни: Например, вы отправляете коллеге ссылку сразу на нужную вкладку, а не объясняете по шагам, куда нажимать.

Переходы из SEO/Wordstat

Простыми словами: Статья может создаваться напрямую из избранной Wordstat-фразы в разделе SEO.

Зачем это нужно: Связка между SEO-исследованием и контентом работает без ручного копирования.

Пример из жизни: Например, вы продаёте кухни и хотите понять, что люди ищут чаще: «кухня на заказ» или «кухня под ключ».
