## 💡 Рекомендации

### Когда рефакторить?
- Файл > 500 строк → **подумать**
- Файл > 1000 строк → **обязательно**
- Тяжело найти код → **сейчас**
- Частые конфликты → **срочно**

### Как рефакторить?
1. Выделить константы
2. Выделить утилиты
3. Выделить логику (reducer)
4. Разбить UI на компоненты
5. Главный файл — только оркестрация

### Правила
- **Один файл = одна задача**
- **Избегать циклических зависимостей**
- **Давать понятные имена**
- **Документировать публичные функции**
