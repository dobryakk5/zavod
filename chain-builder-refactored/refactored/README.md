# Рефакторинг Chain Builder

## Зачем рефакторить большие файлы?

**ДА, стоит!** Вот почему:

### Проблемы больших файлов (1000+ строк):
- 🔍 Сложно найти нужный код
- 🐛 Легко внести баги при изменениях
- 👥 Конфликты при работе в команде
- 🧪 Сложно тестировать
- 🔄 Сложно переиспользовать код

### Преимущества модульной структуры:
- ✅ Быстрая навигация по проекту
- ✅ Изолированные изменения
- ✅ Легче тестировать отдельные модули
- ✅ Проще переиспользовать компоненты
- ✅ Параллельная работа над разными частями

## Предлагаемая структура

```
chain-builder/
├── package.json          # Зависимости проекта
├── ChainBuilder.jsx      # Главный компонент (~230 строк) ✅
├── constants.js          # Константы (~35 строк) ✅
├── utils.js              # Утилиты (~105 строк) ✅
├── reducer.js            # Редюсер состояния (~80 строк) ✅
├── mockApi.js            # API и тестовые данные (~55 строк) ✅
└── components/
    ├── Toolbar.jsx       # Верхняя панель (~85 строк) ✅
    ├── NodeCard.jsx      # Карточка узла (~185 строк) ✅
    ├── EdgeLine.jsx      # Линия связи (~60 строк) ✅
    ├── NodeEditorModal.jsx   # Редактор узла (~340 строк) ✅
    └── ContextMenu.jsx   # Контекстное меню (~20 строк) ✅
```

## Когда рефакторить?

- Файл > 500 строк → подумать о разделении
- Файл > 1000 строк → обязательно разделить
- Сложно найти код → время рефакторить
- Часто конфликты в git → разделить на модули

## Правила хорошего разделения

1. **Один файл = одна ответственность**
   - constants.js только константы
   - utils.js только утилиты
   - Toolbar.jsx только тулбар

2. **Логическая группировка**
   - Все компоненты в `components/`
   - Все утилиты в `utils/`

3. **Минимум зависимостей**
   - Избегать циклических импортов
   - Четкая иерархия зависимостей

4. **Понятные имена**
   - `NodeCard.jsx` вместо `Card.jsx`
   - `formatTime()` вместо `format()`

## Результат

✅ **Рефакторинг завершён!**

Все компоненты вынесены в отдельные файлы. Каждый модуль отвечает за свою задачу, легко тестируется и поддерживается.

## Как использовать

1. Скопируйте все файлы из папки `refactored/`
2. Установите зависимости: `npm install`
3. Запустите: `npm run dev`
4. Импортируйте главный компонент:
   ```jsx
   import ChainBuilder from './ChainBuilder';
   
   function App() {
     return <ChainBuilder />;
   }
   ```
