# Zavod - Автоматизированная система маркетинга

Zavod - это комплексная платформа для автоматизации маркетинга, генерации контента и анализа данных. Система помогает бизнесам создавать и публиковать контент, анализировать конкурентов и оптимизировать свои маркетинговые усилия.

## Особенности

- **Автоматическая генерация контента**: Создание текстов, изображений и видео с помощью ИИ
- **SEO оптимизация**: Работа с Wordstat, семантика, карта ниши
- **Анализ конкурентов**: Сканирование чужих каналов и анализ контента
- **Планирование публикаций**: Интеграция с социальными сетями
- **CRM-система**: Управление клиентами, событиями, платежами и заметками
- **Аналитика и отчеты**: Еженедельные отчеты и статистика

## Новая функциональность: CRM-система

В последнем обновлении добавлена полнофункциональная CRM-система, которая позволяет:

### Управление клиентами
- Создание и редактирование клиентов
- Категоризация клиентов
- Поддержка иерархии (родитель-дочерний клиент)
- Добавление заметок и комментариев

### Управление событиями
- Планирование встреч и консультаций
- Отслеживание статуса событий
- Категоризация типов событий

### Управление платежами
- Отслеживание оплат от клиентов
- Статусы платежей (ожидание, оплачено, ошибка, возврат)
- Поддержка разных валют

### Управление заметками
- Создание важных заметок о клиентах
- Поиск и фильтрация заметок
- Организация информации

### Интерфейс
- Современный веб-интерфейс с использованием Shadcn UI
- Поддержка иерархии клиентов с возможностью раскрытия/сворачивания
- Адаптивный дизайн для разных устройств

### API
- Полный набор REST API для интеграции
- Поддержка фильтрации, сортировки и поиска
- Аутентификация через JWT токены
- Проверка прав доступа

## Архитектура

Система построена на Django/Django REST Framework с использованием следующих технологий:

- **Backend**: Python, Django, Django REST Framework
- **Frontend**: React, Next.js, TypeScript
- **UI Components**: Shadcn UI
- **Database**: PostgreSQL
- **Authentication**: JWT
- **File Storage**: AWS S3 или локальное хранилище
- **Task Queue**: Celery (опционально)

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Настройте переменные окружения
4. Выполните миграции:
   ```bash
   python manage.py migrate
   ```
5. Запустите сервер:
   ```bash
   python manage.py runserver
   ```
